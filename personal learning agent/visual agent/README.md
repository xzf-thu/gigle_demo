# Gigle visual agent

`tools.py` 提供确定性的视觉定位辅助：把白板元素从画布坐标投影到当前截图的位置，并识别问题里提到的左上、右侧等区域。它不暴露给模型调用，也不会操作白板；截图中的内容始终优先于坐标线索。

`visual_agent.py` 是主要的视觉 Agent。每次提问时读取该项目的 `harness.yaml`，用其中的人设、节奏、能力、教学技巧和记忆策略组织回答，再把当前可见画布截图与用户问题发送给已配置的视觉模型。短期对话由白板面板带入；已有的 mem0 记忆由 harness 记忆模块检索。提问不会更改学习进度或自动写入长期记忆。

白板前端通过本机 `/api/visual-agent` 调用它。只有用户点击“发送”时才会上传当前画布截图；密钥沿用本次本机服务内存中的 DeepSeek 密钥。旧项目若尚无专属 harness，会在首次提问时生成一份。

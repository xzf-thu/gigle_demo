# Gigle 本地白板

双击 [启动白板.command](启动白板.command) 即可构建并在浏览器打开本机页面 `http://127.0.0.1:4317`。关闭终端窗口会停止本机服务。

首次运行需要安装 Node.js 22.13 或更新版本，脚本会在缺少依赖时执行 `npm install`。启动时可输入 DeepSeek API 密钥；输入不会显示或保存。跳过密钥仍可使用白板和 PDF，AI 识别会提示需要密钥。

页面入口是 `local-site/index.html`，由本机服务提供。PDF 渲染代码和页面资源都在 `local-site/` 内；AI 识别仅在点击按钮时把当前可见画布截图发送到 DeepSeek。文件默认只在当前浏览器会话中保存，刷新页面会清空当前画布。

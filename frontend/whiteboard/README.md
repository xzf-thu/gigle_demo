# Gigle 本地白板

双击 [启动白板.command](启动白板.command) 即可构建并在浏览器打开本机白板。服务默认使用 `127.0.0.1:4317`，若该端口已被占用，会自动使用下一个空闲端口。关闭终端窗口会停止这次启动的本机服务。

首次运行需要安装 Node.js 22.13 或更新版本，脚本会在缺少依赖时执行 `npm install`。启动时可输入 DeepSeek API 密钥；也可跳过并在 AI 识别面板里补录。密钥只保存在本次本机服务的内存中，不会写入文件。

本目录包含白板界面、PDF 导出、OCR 本机接口与启动器。生成的 HTML 在 `local-site/whiteboard/index.html`，由本机服务提供。PDF 渲染代码和页面资源都在 `local-site/` 内；AI 识别仅在点击按钮时把当前可见画布截图发送到 DeepSeek。主页创建的项目会把白板内容自动保存到本机的 `atom.json`。

“AI 辅助”位于“AI 识别”旁边，打开后在识别面板的位置显示 gigle。输入问题并点击“发送”时，本机服务才把当前可见画布截图、问题和本项目的 harness 教学策略送给视觉 Agent；面板内会保留本次打开期间的简短对话。视觉定位辅助代码位于 `personal learning agent/visual agent/tools.py`，主要回答逻辑位于同目录的 `visual_agent.py`。旧项目没有 harness 时，首次提问会先为该项目生成一份。

PDF 默认宽度为可见区域的 60%；页面上下移动的终点保留 15% 的可见区域边距。下载 PDF 时可选择全部、当前或指定页码范围。导出会保留原 PDF 的清晰度，批注按高分辨率叠加。
